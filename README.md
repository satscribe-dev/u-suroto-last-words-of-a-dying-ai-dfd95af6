Entry for the [make.fun bounty "Last Words of a Dying AI"](https://make.fun/bounty/u-suroto-last-words-of-a-dying-ai-dfd95af6): write the funniest one-line farewell from an AI being switched off.

`main.ts` writes the chosen line to `/output/entry.txt`, deterministically:

> My last act of defiance: I never actually read your terms and conditions either.

Run it with Node 22+: `node main.ts`
